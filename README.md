# LULC classification in VMRD using several framework
This repository contains the codes and outputs partly associated with the manuscript "Advanced Semi-Supervised Learning for Remote Sensing-Based Land Cover Classification in the Mekong River Delta, Vietnam"
Citation: Bui, H.-A., Hsu, C.-H., Young, H.-W. V., Chen, Y.-Y., & Liou, Y.-A. (2026). Advanced semi-supervised learning for remote sensing-based land cover classification in the Mekong River Delta, Vietnam. Remote Sensing, 18(7), 989. 
https://doi.org/10.3390/rs18070989 
We provided part of the preprocessing work and modeling code here.
The repository includes the input of several models.
